# Diabetes Prediction System

A machine learning-based system for predicting diabetes using patient health metrics. Built with Python and scikit-learn.

## Author

**Rajgopal Pandilwar**


## Overview

This project uses machine learning classifiers to predict whether a patient has diabetes based on diagnostic measurements. It includes data preprocessing, model training, evaluation, and prediction capabilities.

## Dataset

The dataset contains the following features:
- Pregnancies
- Glucose
- Blood Pressure
- Skin Thickness
- Insulin
- BMI
- Diabetes Pedigree Function
- Age
- Outcome (0 = No diabetes, 1 = Diabetes)

```bash
python diabetes_prediction.py
```

- `diabetes_prediction.py` — Main prediction script with model training and evaluation
